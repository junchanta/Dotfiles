# リポジトリの公開

2026-11-22 に、このリポジトリを公開した。
その経緯を残す。

# 決定事項と理由

## 履歴は、Nix に移行したコミットから始める

- それより前の履歴には、公開に向かない内容が残っていた
    - ファイルを消しても履歴には残るので、履歴ごと切り離した
    - 今の構成とは関係のない古い設定なので、切り離しても経緯は失われない
- 古い履歴は、非公開のリポジトリ `Dotfiles-archive` に残してある
- 切り離した後の各コミットは、中身、メッセージ、日時を元のままにしている
    - 作者のメールアドレスの誤記だけを直した

## 公開の前に、公開する範囲をすべて調べる

- 対象は、全コミットの全ファイル(消した行も含む)と、コミットのメッセージである
- スキャナ(gitleaks)と自前のパターンで、認証情報を探した
- 文章の中身は、機械では見つけられないので、通読した

## 公開した後の決まり

- 認証情報と、仕事に関わる情報(会社名、社内の URL、プロジェクト名など)は入れない
- push した時点で公開されるので、push の前に差分を確かめる
